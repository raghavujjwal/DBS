# DBS Study Guide

CS F212 Database Systems comprehensive exam preparation guide for BITS Pilani.

**Live site:** [https://raghavujjwal.github.io/DBS/](https://raghavujjwal.github.io/DBS/)

## What's inside

- **Topic-wise Study Guide** — 20 topics, each broken down into Factual / Conceptual / Solving question types
- **PYQ Breakdown** — Every question from 4 years of compre papers (2017-18, 2021-22, 2022-23, 2023-24) tagged by topic, type, and difficulty
- **Quick Reference** — Formulas, algorithms, decision trees for last-minute revision

## How it works

Built with Jekyll and hosted on GitHub Pages. Push to `main` to deploy.

## Local development

```bash
bundle install
bundle exec jekyll serve
```
